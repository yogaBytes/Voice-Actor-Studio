# Voice Actor Studio

Voice Actor Studio is an Android character-chat and voice-actor studio designed with offline use in mind.

## Features

- Offline character conversations
- Custom characters and personalities
- Character greetings
- Conversation messages
- Local character memory
- Voice-acting and creative-writing features
- Accessibility designed with TalkBack in mind
- Kids mode with age-appropriate protections

## Project

**Package name:** `com.voiceactorstudio`

**Language:** Java

**Platform:** Android

The project is currently under development.

## Current Components

- `MainActivity.java` — starts the Android application
- `Character.java` — defines character information
- `ChatMessage.java` — represents conversation messages
- `OfflineChatEngine.java` — provides the initial offline response system

More features will be added as development continues.
